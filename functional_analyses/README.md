# Functional Analyses

These scripts perform analyses between polyphenol intake (total, class, compound) and PUP gene counts as well as the abundance of PUP-containing microbial genera. Analyses were run with (rank-based estimation regression) and without covariates (Spearman correlation). Covariates included: Age, Sex, BMI, Fiber Intake (g/1000 kcal), and diet quality (Total HEI-2015 Score). Summary plots for covariate-adjusted models were created.
